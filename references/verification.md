# 证据与反向核验

## 证据索引

工程报告维护 `ID | 算法阶段 | 核心结论 | 相对路径·符号·实际行号 | 生效条件/可达性 | CODE/RUN/DOC/INFER/OPEN`。表头绑定 commit，脏文件关联哈希。算法正文引用稳定证据 ID。

RUN 记命令、输入、有效配置、环境、实际输出及容差；DOC 给版本/来源链接，与代码分述；INFER 给依据、范围和反证条件。重要 OPEN 记录缺什么、已查什么、影响哪些结论、下一步如何验证。引用必须来自实际读取；Notebook 用原 JSON 实际行范围加 cell 标识，不能冒用抽取脚本的行号。第三方证据独立标来源/版本。

## 可选机械检查

技能目录下运行（输出放仓库外）：

```text
python scripts/repo_snapshot.py LOCAL_REPO --output snapshot.json
python scripts/check_evidence.py --repo LOCAL_REPO --evidence evidence.json
```

需要 Python 3.8+ 和 Git。快照含完整 HEAD、分支、脱敏 origin、UTC、暂存/工作树变化及指纹、子模块状态；不代替资源和环境调查。引用文件格式如下，值必须由实际读取获得：

```json
{"commit":"完整HEAD","records":[
  {"id":"E01","path":"src/solver.py","symbol":"step",
   "start":12,"end":25,"sha256":"实际文件SHA256"}
]}
```

`records` 必须非空。路径使用 Git 根下规范的 `/` 相对路径，行号从 1 开始含首尾。JSON 可有 UTF-8 BOM，源码需 UTF-8；二进制、特殊编码、生成代码、外部依赖另记证据和未覆盖原因。工具只检查版本、范围、路径和指纹，不证明符号可达、公式正确或结论成立。不用脚本也须核对身份。

快照不是并发原子快照；采集时避免其他写入，并在关键分析结束后复核。忽略文件不会自动记录，暂存内容以 Git blob ID 识别。脱敏仅覆盖 URL 用户信息、查询参数和片段，输出前仍检查自定义远程路径中的敏感内容。文件指纹按原始字节计算，CRLF/LF 差异会导致失配，应记录换行差异后重新核实，不能无条件忽略。已安装轮子的版本号相同不证明它由所读 commit 编译；分别记录源码身份和实际加载模块/二进制身份。

## 六项核验与修订

1. 从输入沿算法到最终输出，检查遗漏的表示转换、索引映射及后处理。
2. 每个关键阶段回查源码及生效条件；反查核心代码是否在抽象中遗漏。
3. 对齐符号、维度/轴、归一化、权重、舍入、更新先后与停止条件。
4. 检查伪代码无未启用路径混入，分支边界/默认值/失败回退齐全。
5. 比较现有测试或微型案例的实际输出、中间状态、不变量；仅能导入不算算法验证。
6. 主动寻找能推翻解释的配置覆盖、备用实现、边界、后端；记录发现及修订。

涉及阈值、精确零判断或离散选择时，同时核对连续中间量和最终分支/标签/掩码。连续量在容差内接近，不能证明离散输出一致；除法与乘倒数等代数等价变形也可能改变实际路径。出现差异先定位到算术或分支，不用放宽容差掩盖。

再做去名/复现检查。遗漏则返回补查，更新报告和证据；缺证据保留缺口。静态一致性不等于运行成功或算法正确性证明。

## 运行及清理

优先现有测试、小输入、固定种子的合成案例，针对关键阈值/梯度/顺序/排序/配置选择验证。不默认完整训练、大实验、下载权重/大数据或装庞大环境。无法运行继续静态核验，写真实原因与未验证行为。

运行记录标明执行对象：原入口、抽取的原函数、兼容适配后的模型，或独立重写的数学流程。列出抽取边界、适配及替换的输入/权重/配置；某一层通过不能替代完整原项目运行证据。

验证前登记临时目录及基线，在隔离目录写测试、控制字节码及库缓存。人为制造误判场景仅改隔离副本，标**合成变更**，不能冒充上游事实。先将命令、输入、结果摘要和指纹等最小复现证据保存到交付报告，再清理本次明确创建的文件。递归删除前核实绝对路径在登记范围内且无重解析点越界；不用全库 clean，不删除用户未知文件。清理后复查原仓库状态；交付证据保留。
